Dark mode with a cookie

Toggle the theme, then reload the page or close and reopen the tab. The theme stays, because it is saved in a cookie for 7 days.

Why a cookie and not localStorage?

Both work here. A cookie has one extra power: the server also gets it with every request. So a server-rendered app (Next.js, Rails, Django) can render the right theme in the very first HTML, with no white "flash" before JavaScript runs. localStorage is only visible to JavaScript.

Cookie: theme=dark   ← sent to the server on every request to this site
